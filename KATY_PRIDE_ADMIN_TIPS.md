# 🌈 Katy Pride Admin Tips & Best Practices

## 🎯 **Making Admin Life Easier**

### **Daily/Weekly Tasks**
- **Check new events** - Add any upcoming board meetings or community events
- **Update homepage photos** - Rotate carousel images monthly
- **Review forms** - Make sure signup forms are working

### **Monthly Tasks**
- **Refresh carousel** - Add new photos from recent events
- **Update resources** - Add new community partners
- **Check links** - Make sure all external links still work

---

## 📸 **Photo Guidelines**

### **Perfect Homepage Photos**
- **Size**: Horizontal (wide) photos work best
- **Content**: People, events, community activities
- **Quality**: Bright, clear, professional-looking
- **File size**: Under 2MB for fast loading

### **Great Event Photos**
- **Size**: Square or horizontal
- **Content**: Event flyers, venue photos, past event pictures
- **Text**: Include event name in photo if possible

---

## 📝 **Content Writing Tips**

### **Event Descriptions**
- **Keep it simple**: What, when, where, why
- **Include details**: Cost, registration, accessibility
- **Add personality**: Use friendly, welcoming language

### **Page Text**
- **About page**: Focus on mission and community impact
- **Advocacy page**: Include current issues and calls to action
- **Resources page**: Brief, helpful descriptions

---

## 🔗 **Link Management**

### **Form Links**
- **Test before publishing**: Click every link
- **Use clear names**: "Volunteer Signup" not "Form 1"
- **Keep current**: Remove outdated forms
- **Order by importance**: Most important first

### **External Links**
- **Check monthly**: Links can break over time
- **Open in new tab**: Better user experience
- **Add descriptions**: Tell people what they'll find

## 🚀 **Pro Admin Workflows**

### **Adding New Event (5 Minutes)**
1. **Content Manager** → **Event** → **+ Create**
2. **Title**: Clear, descriptive name
3. **Date/Time**: Use calendar picker
4. **Location**: Full address if in-person
5. **Photo**: Upload relevant image
6. **Description**: What to expect, how to join
7. **Link**: Registration if needed
8. **Published**: Toggle ON
9. **Save** → **Publish**

### **Updating Homepage Photos (10 Minutes)**
1. **Content Manager** → **Carousel Image**
2. **Review current photos**: Toggle old ones OFF
3. **+ Create new entry** for each new photo
4. **Upload**: Choose best recent event photos
5. **Title**: Describe the photo/event
6. **Alt text**: Help accessibility
7. **Active**: Toggle ON
8. **Save** → **Publish**
9. **Check website**: Refresh to see changes

### **Adding New Form (3 Minutes)**
1. **Content Manager** → **Form Link** → **+ Create**
2. **Title**: Clear button text
3. **URL**: Copy/paste form link
4. **Page**: Where should it appear?
5. **Active**: ON
6. **Order**: Number for position
7. **Save** → **Publish**
8. **Test**: Click the button on website

## 🆘 **Common Issues & Solutions**

### **"My changes aren't showing!"**
- **Solution**: Did you click Publish? Save isn't enough!
- **Wait**: Website updates can take 2-3 minutes
- **Refresh**: Hard refresh (Ctrl+F5) the website

### **"The photo looks weird!"**
- **Solution**: Use horizontal (landscape) photos
- **Size**: Keep under 2MB file size
- **Quality**: Use bright, clear images

### **"I can't find the content type!"**
- **Solution**: Look in Content Manager (left menu)
- **Search**: Use the search bar at the top
- **Sections**: Events, Carousel Images, Form Links, etc.

### **"I accidentally deleted something!"**
- **Don't panic**: Most content can be recreated
- **Check**: Look in the trash/recently deleted
- **Recreate**: Use this guide to rebuild
