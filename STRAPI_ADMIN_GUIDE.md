## 📋 What You Can Manage (Simple Version)

### 🏠 **Homepage Images** (Carousel)
**What it does**: Changes the photo slideshow on the homepage
**How to update**:
1. Click **Content Manager** (left menu)
2. Click **Carousel Image**
3. Click **+ Create new entry** (top right)
4. **Title**: Give the photo a name
5. **Image**: Click upload → choose your photo
6. **Alt Text**: Describe the photo for accessibility
7. **Active**: Toggle ON to show, OFF to hide
8. Click **Save** → **Publish**

### 📅 **Events** 
**What it does**: Adds events to the /events page
**How to add an event**:
1. Click **Content Manager** → **Event**
2. Click **+ Create new entry**
3. **Title**: Event name (e.g., "Monthly Coffee Meetup")
4. **Start**: Click calendar → select date/time
5. **End**: Same as start for most events
6. **Location**: Where is it happening?
7. **Image**: Upload event photo
8. **Summary**: Event details (like a flyer)
9. **External URL**: Registration link (if needed)
10. **Published**: Toggle ON to show on website
11. Click **Save** → **Publish**

### 🔗 **Form Links** (Signup Forms)
**What it does**: Creates signup buttons on pages
**How to add a form**:
1. Click **Content Manager** → **Form Link**
2. Click **+ Create new entry**
3. **Title**: Button text (e.g., "Volunteer Signup")
4. **URL**: The form link
5. **Page**: Which page shows this button
6. **Active**: Toggle ON to show
7. **Order Rank**: 1 = first button, 2 = second, etc.
8. Click **Save** → **Publish**

### 📚 **Resources** (Helpful Links)
**What it does**: Adds helpful organizations to /resources page
**How to add a resource**:
1. Click **Content Manager** → **Resource Link**
2. Click **+ Create new entry**
3. **Name**: Organization name
4. **URL**: Their website
5. **Category**: Pick the best category
6. **Description**: What they help with
7. **Active**: Toggle ON to show
8. Click **Save** → **Publish**

## 🎨 **Page Content** (Text Updates)

### About Page, Advocacy Page, etc.
**What it does**: Changes text on website pages
**How to edit**:
1. Click **Content Manager** → **Page Content**
2. Find the page you want to edit (search by page name)
3. Click the entry to edit
4. **Heading**: Main title
5. **Intro**: Main text content
6. Click **Save** → **Publish**

## ⚠️ **Important Rules**

### ✅ **DO**
- Always click **Save** AND **Publish** (both buttons!)
- Use clear, simple titles
- Add good photos (horizontal work best)
- Check spelling before publishing
- Test links after publishing

### ❌ **DON'T**
- Don't delete things unless you're sure
- Don't forget to click **Publish**
- Don't use huge photos (they load slowly)
- Don't leave required fields blank

## 🆘 **Troubleshooting**

### **"I don't see my changes!"**
- Did you click **Publish**? (Save isn't enough!)
- Wait 2-3 minutes for website to update
- Refresh the website page (Ctrl+F5)

### **"I can't find the content type!"**
- Look in **Content Manager** (left menu)
- Use the search bar at the top
- Check if you're in the right section

### **"The photo isn't showing!"**
- Is **Active** toggled ON?
- Did you click **Publish**?
- Is the photo file size too big?

### **"I made a mistake!"**
- Don't panic! Find the entry → edit → fix → save → publish
- Or toggle **Active** OFF to hide it temporarily
