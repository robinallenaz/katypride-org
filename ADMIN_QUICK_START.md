# 🚀 Katy Pride Admin Quick Start

## 🎯 One-Page Summary for Board Members

### **Step 1: Access Admin Panel**
🔗 **URL**: https://katypride-7x4qno1sj-robinallenazs-projects.vercel.app/admin
📱 **Bookmark this page!**

### **Step 2: What You Can Do**

| What You Want | Where to Click | What to Do |
|---------------|-----------------|------------|
| **Add Event** | Content Manager → Event | + Create → Fill details → Save → Publish |
| **Change Homepage Photos** | Content Manager → Carousel Image | + Create → Upload photo → Active ON → Save → Publish |
| **Add Signup Form** | Content Manager → Form Link | + Create → Add link → Choose page → Save → Publish |
| **Edit Page Text** | Content Manager → Page Content | Find page → Edit text → Save → Publish |
| **Add Resource Link** | Content Manager → Resource Link | + Create → Add organization → Save → Publish |

### **Step 3: Golden Rules**
✅ **Always click BOTH Save AND Publish**  
✅ **Use horizontal photos**  
✅ **Test your links**  
❌ **Don't delete unless you're sure**  

### **Step 4: If Something Goes Wrong**
1. **Refresh website** (Ctrl+F5)
2. **Wait 2-3 minutes**
3. **Check if you clicked Publish**
4. **Toggle Active OFF/ON**
