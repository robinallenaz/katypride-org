## 🎨 Admin Experience & Training

### 📱 **Admin Dashboard Access**
**URL**: `https://katypride-strapi.onrender.com/admin`

### 👥 **What Board Members Can Manage**

#### 🏠 **Homepage Carousel Images**
1. Login to admin panel
2. Click **Content Manager** → **Carousel Image**
3. Click **+ Create new entry**
4. Upload photo, add title and alt text
5. Toggle **Active** to show on homepage
6. Click **Save** → **Publish**

#### 📅 **Events & Calendar**
1. **Content Manager** → **Event**
2. Add event details: title, date, location, description
3. Upload event image
4. Set recurrence for regular meetups
5. Click **Save** → **Publish**

#### 🔗 **Forms & Signups**
1. **Content Manager** → **Form Link**
2. Add form title and URL
3. Select which page shows the form
4. Set order and activate
5. Click **Save** → **Publish**

#### 📚 **Community Resources**
1. **Content Manager** → **Resource Link**
2. Add organization name, website, category
3. Write brief description
4. Click **Save** → **Publish**

### ⚡ **Training Time Required**
- **New Board Member**: **15 minutes** basic training
- **Content Updates**: **2-3 minutes** per change
- **Event Addition**: **5 minutes** complete process
- **Photo Updates**: **3 minutes** per carousel image
